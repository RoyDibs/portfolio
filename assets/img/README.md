# Photos

Drop your conference / lab / travel photos here. The gallery in `js/gallery.js`
looks for these filenames by default — either name your files to match, or edit
the `PHOTOS` list in `js/gallery.js`:

| filename | suggested caption |
|---|---|
| `conf-1.jpg`   | ICML 2026 · presenting CINOC |
| `lab-1.jpg`    | Argonne · Polaris supercomputer |
| `conf-2.jpg`   | SIAM CSE25 · surrogate modeling |
| `team-1.jpg`   | The Goswami Lab · Johns Hopkins |
| `conf-3.jpg`   | Weimar Spring School 2026 |
| `travel-1.jpg` | On the road |
| `poster-1.jpg` | EMI 2025 poster |
| `talk-1.jpg`   | IEEE CDC 2026 |

**Tips**
- Any image format works (`.jpg`, `.png`, `.webp`) — just keep the filename in sync with `gallery.js`.
- Aim for landscape ~1600px wide; they're cropped to fill.
- Missing files fall back to a styled placeholder, so the layout never breaks.

You can pull your existing photos from your Framer site: <https://dibakar.framer.website/>
